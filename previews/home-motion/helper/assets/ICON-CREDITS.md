# Helper completion icons

`rating-star.png` is the unchanged 512px PNG from
[Star 1828884 by Pixel perfect on Flaticon](https://www.flaticon.com/free-icon/star_1828884),
downloaded on 2026-10-16 from
<https://cdn-icons-png.flaticon.com/512/1828/1828884.png>.
The source page specifies the free Flaticon license with required attribution.
The unselected UI state applies CSS grayscale and opacity to this same image.

The completion card also reuses the existing local `trophy.png` (setiawanap)
and `hands.png` (smashingstocks) from `../../activity/assets/icons/`; their
source records are in that folder's `ATTRIBUTION.md`. No copies are needed.

Visible, linked author and Flaticon credits appear below the completion actions.
Keep them when reusing the design. These assets are incorporated in the app
preview and are not an icon collection for standalone redistribution.
