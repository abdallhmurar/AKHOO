فتح التطبيق

أُصلحت مشاكل التداخل، اتجاه العناصر، الأرقام المختلطة، تباين الوضع الليلي وتبديل الفيديو بحسب حالة الطلب. استُخدمت نفس الرسومات والمقاطع المعتمدة، دون إعادة تصميم الهوية أو تغيير عمليات الطلبات والحسابات.

نطاق الفحص وطريقته

فحص بصري داخل Chrome للغات العربية والعبرية والإنجليزية، مع RTL للعربية والعبرية وLTR للإنجليزية. شمل مقاسات فعلية مقاسة داخل الصفحة: 320×740 و390×844 للموبايل، وفحص تمركز صفحة الطلب عند 1280×900. اختُبرت عينات بالوضعين الفاتح والليلي. هذه مقاسات محاكاة داخل متصفح الكمبيوتر، وليست نتائج اختبار أجهزة iPhone أو Android فعلية.

استُخدمت المشاهدة، قياسات حدود النص والصور، حالة عناصر الفيديو وقراءة أخطاء المتصفح، إضافةً إلى فحص الكود والاختبارات. استُخدمت طلبات مكتملة موجودة لعرض شاشات النجاح؛ لم يُرسل طلب جديد أو تقييم أو رسالة، ولم تتغير حالة مهمة أو تُستبدل نقاط.

نتائج التحقق التقني والنشر

  • نجاح فحص TypeScript وفحص ESLint للملفات المعدّلة.
  • نجاح 195 اختبارًا في 34 ملف اختبار، مع اختبارات جديدة لتطابق متغيرات الترجمة وعزل الأرقام وصيغة الوقت المفردة.
  • نجاح بناء نسخة الويب، ومطابقة ملف JavaScript المنشور مع البناء المحلي المفحوص.
  • استجابة مسارات التطبيق الرئيسية بالرمز 200 بعد النشر، دون خطأ 404 في المسارات المفحوصة.
  • فحص 54 ملفًا من ملفات الحركة على رابط الإنتاج؛ جميعها متاحة. المقاطع الـ12 تدعم استجابة 206 لطلبات أجزاء الفيديو، وبنوع video/mp4 الصحيح.
  • ملف فيديو غير موجود يعيد 404 بدل صفحة HTML، لتبقى معالجة فشل الوسائط صحيحة.

حدود النتيجة

هذا تدقيق بصري وتقني للواجهة المحدّثة، وليس إثباتًا بأن كل مسار أعمال وكل متصفح وكل نص ديناميكي ممكن قد اختُبر. لم تُنشأ طلبات أو تُقبل مهام أو تُرسل رسائل أو تقييمات أو تُستبدل عروض أثناء التدقيق. لم تُفعّل إتاحة المساعد بغرض الفحص لأن فتح هذه الصفحة قد يغيّر الإتاحة الفعلية. لذلك فحص حالات الانتظار والقبول والتأكيد المتصل بطرفين يظل بحاجة إلى حسابات وطلبات اختبار مخصصة.

لم تُختبر أجهزة iOS وAndroid الفعلية أو Safari وFirefox. محتوى العروض الذي يدخله أصحابها وترجمته الآلية لم يُعدّل كبيانات إنتاج. التقرير لا يتضمن بيانات الحسابات أو أرقام الطلبات الحقيقية.

أُعيدت لغة المعاينة إلى العربية والوضع الفاتح، وأُزيلت محاكاة الموقع والحركة وأبعاد الجهاز بعد الفحص.
