# Approved web home artwork

These assets are copied unchanged from the approved local prototype at
`previews/home-motion/assets` on branch `preview/home-motion-20261015`, commit
`6a701f186ec5a15d90bdd0d1e78030058e0ea793`.

The two six-second MP4 clips and their posters were generated in Grok for this
project. The road header and text-free illustration plate were generated with
the built-in image tool. The original prompts and preview history remain on
that branch. `home-art.png` supplies only the rewards artwork through a CSS
background crop; all labels and buttons are real localized UI.

Only web components import these assets. Native home components and existing
Android/iOS assets remain unchanged.
